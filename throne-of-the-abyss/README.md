# Throne of the Abyss

Оригинальная dark-fantasy action RPG в жанре soulslike с видом от третьего лица.
Мир — **Эльдракар**, королевство после Катаклизма; герой — **Безымянный Наследник**.

> Движок: **Three.js (WebGL 2) + TypeScript + Vite**. Unreal Engine 5 в среде разработки
> недоступен, поэтому вместо фиктивного UE5-проекта архитектура перенесена на веб-стек
> (соответствия UE-понятиям — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)).

## Запуск

Требуется Node.js 20+ и браузер с WebGL 2 (Chrome, Edge, Firefox, Safari 15+).

```bash
cd throne-of-the-abyss
npm install
npm run dev
```

Откройте адрес, который выведет Vite (по умолчанию http://localhost:5173), нажмите
**New Game** и кликните по экрану, чтобы захватить мышь.

Сборка и проверка:

```bash
npm run build      # проверка типов + production-сборка в dist/
npm run preview    # запуск собранной версии
npm test           # юнит-тесты (vitest)
npm run smoke      # автоматический плейтест в headless Chromium (нужен playwright)
```

`npm run smoke` использует пакет `playwright` с установленным Chromium
(`npm i -D playwright && npx playwright install chromium`). Скриншоты пишутся в `artifacts/`.

Параметры URL для разработки: `?quality=low|medium|high|ultra`, `?skipTitle=1`
(сразу новая игра), `?test=1` (без захвата указателя, открыт `window.__TOA`).

### Один HTML-файл

```bash
npm run build:single
```

Собирает игру в один файл `dist-single/throne-of-the-abyss.html` (код, стили и шрифты
внутри). Его можно открыть двойным щелчком, без сервера и интернета.

## Что реализовано (рабочее, проверено тестами)

- **Персонаж**: ходьба/бег/спринт, прыжок, перекат и отскок с окнами неуязвимости,
  лёгкие комбо, тяжёлая и заряженная атаки, атака с разбега, после переката, в прыжке
  и в падении (с ударной волной), блок с расходом выносливости и пробитием защиты,
  парирование → рипост, удар в спину, предметы, заклинания, захват и смена цели.
- **Бой**: фреймдата (startup / active / recovery), буфер ввода, окна отмены, трекинг
  только в фазе замаха, свип-хитбоксы клинка (капсула против капсулы), hit-stop, тряска
  камеры, шлейфы ударов, искры/кровь, реакции (вздрагивание / стаггер / нокдаун),
  равновесие (poise) и гиперброня.
- **Урон**: 9 типов (Physical, Fire, Ice, Lightning, Holy, Dark, Arcane + накопительные
  Poison, Bleed), масштабирование от характеристик, требования оружия, защита
  с убывающей эффективностью, сопротивления/слабости, крит, контр-удар, баффы/дебаффы.
- **RPG**: 7 характеристик, soft caps, уровни за «Эхо» (валюта), повышение у алтаря.
  Броня по 4 слотам (голова, корпус, руки, ноги) — поглощение урона, равновесие,
  сопротивления, вес; смена брони меняет внешний вид героя. Два кольца и амулет
  с пассивными эффектами. Вес снаряжения задаёт тип переката (лёгкий / средний /
  тяжёлый / перегруз).
- **Оружие**: 10 видов для игрока в 10 классах — прямой меч, двуручный меч, копьё,
  алебарда, кинжал, топор, молот, катана, посох, гримуар; у каждого свой набор атак
  и **навык оружия** (атакующий или усиливающий). Посох и гримуар усиливают магию.
- **Магия**: 18 заклинаний в 9 школах — некромантия, чёрная магия, огонь, лёд, молния,
  святая, пространственная, кровь (платится здоровьем), призыв (призрачный рыцарь-союзник).
  Снаряды, взрывы, метеор, удар молнии, разлом с притяжением, заморозка, вытягивание
  жизни, лечение, усиления.
- **Добыча**: 6 сундуков и 9 предметов по замку и открытому миру; элитный рыцарь
  оставляет свой комплект брони и печатку.
- **ИИ врагов**: восприятие (дистанция, угол обзора, препятствия, шум, шкала тревоги),
  патруль, расследование, преследование, тактическое кружение со щитом, токены атаки
  (не больше двух атакующих одновременно), уклонение, отступление, наказание за лечение,
  возврат на пост. Элитный рыцарь **Vaelor, the Gravebound** — вступительная сцена,
  две фазы, полоса босса. Главный босс региона **The Fallen King** в Тронном зале:
  контратаки, удары по площади с отметкой на земле, призыв павших рыцарей, вторая фаза
  с раскалыванием доспехов, сцены вступления и победы, уникальная награда.
- **Мир**: замок Ashen Gate (двор, собор, терраса, клуатр, кладбище) и открытый мир
  вокруг: равнины, золотые поля, леса, озёра и река, два каменных моста, руины крепости
  на плато, гигантское древо, далёкие замки на горных отрогах, снежный хребет.
- **Освещение**: динамическое время суток (солнце/луна), погода (ясно / облачно /
  пасмурно / дождь), голубое небо с облаками, солнечные тени, отражения неба (IBL),
  дымка на расстоянии, вода с отражениями (High/Ultra), светлячки ночью.
- **Контрольные точки**: 4 алтаря — отдых (лечение, восстановление флаконов, возрождение
  обычных врагов), повышение уровня, перемещение, «пропустить время».
- **Смерть**: потеря эха и его возврат в месте гибели, возрождение у последнего алтаря.
- **Открытый мир**: миникарта-кружок справа сверху (поворачивается вместе с камерой:
  местность, постройки, алтари, враги, место гибели, название места); 20 мест, которые
  открываются при первом посещении; «туман» на большой карте, который рассеивается
  по мере исследования; стражи у ориентиров по всему королевству.
- **Боссы**: от их атак можно только уклоняться перекатом или защищаться блоком —
  парирование не срабатывает, рипостов и ударов в спину по боссам нет.
- **UI**: HUD (здоровье/мана/выносливость с отложенной полосой урона, статусы, слоты,
  эхо, маркер цели, полосы врагов и босса, подсказки), меню, карта, журнал, записки.
- **Сохранения**: автосохранение и ручное (localStorage, с версией и валидацией).
- **Графика**: профили Low / Medium / High / Ultra. Сглаживание: FXAA на Low,
  аппаратное MSAA 4× (с мягкими краями листвы и травы) на Medium и выше, плюс SMAA
  и мягкое затенение углов (ambient occlusion) на High / Ultra; анизотропная
  фильтрация текстур до 16×.

## Что требует ассетов / ещё не сделано

- Персонажи, оружие и окружение — **процедурные модели из примитивов**; анимации —
  **процедурные ключевые позы** (без скелетной анимации из DCC). Система рассчитана на
  замену: см. «Замена ассетов» в архитектуре.
- **Звука нет** (удалён по решению владельца проекта).
- Облака — 2.5D-слой со светорассеянием, не объёмный ray-marching.
- Из 6 регионов готов один (Ashen Kingdom) с элитой и главным боссом; остальные
  регионы и боссы, NPC и цепочки квестов — в плане
  (см. [docs/ROADMAP.md](docs/ROADMAP.md)).
- Броня меняет цвета, шлем и наплечники процедурной модели; уникальных моделей для
  каждого предмета нет.
