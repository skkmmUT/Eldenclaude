# Архитектура

Проект — модульное TypeScript-приложение на Three.js. Правило: **данные отдельно от
логики** (всё, что балансируется, лежит в `src/data/*`), а системы общаются через
типизированную шину событий, чтобы бой не зависел от UI и эффектов.

## Соответствие понятиям Unreal Engine

| Unreal Engine 5 | Здесь |
|---|---|
| GameMode / GameInstance | `core/Game.ts` — оркестратор, правила, цикл кадра |
| Enhanced Input (Actions + Mapping Contexts) | `input/InputActions.ts`, `data/inputBindings.ts`, `input/InputManager.ts`, `input/InputBuffer.ts` |
| Character + CharacterMovementComponent | `characters/Character.ts`, `physics/CharacterMotor.ts` |
| Animation Blueprint, State Machine, Blend Space, Layered Blend per Bone | `animation/Animator.ts` (кроссфейды, `BlendSpace1D`, маскированные слои) |
| Behavior Tree / State Tree + AI Perception | `characters/enemies/Enemy.ts` (иерархический FSM + выбор атак по весам), `Perception.ts`, `EnemyDirector.ts` (токены атаки) |
| Data Assets / Data Tables | `data/attacks.ts`, `weapons.ts`, `enemies.ts`, `spells.ts`, `items.ts`, `poses.ts`, `lore.ts` |
| Niagara | `vfx/ParticlePool.ts`, `vfx/SlashTrail.ts`, `vfx/VFXManager.ts`, GPU-частицы в `world/Atmosphere.ts`, `environment/Rain.ts` |
| Sky Atmosphere / Volumetric Clouds / Directional Light / Sky Light | `world/environment/*` (`SkyDome`, `CloudLayer`, `EnvironmentSystem`, IBL через PMREM) |
| Landscape + Foliage (HISM) | `world/terrain/Terrain.ts`, `Foliage.ts` (инстансы по чанкам) |
| Level Streaming / HLOD | `world/StaticBatcher.ts` (слияние статики по материалу и ячейке), скрытие чанков растительности по дистанции |
| SaveGame | `save/SaveSystem.ts` |
| UMG | `ui/HUD.ts`, `ui/Menus.ts` (DOM-оверлей) |
| Scalability settings | `render/GraphicsSettings.ts` (Low/Medium/High/Ultra) |

## Структура `src/`

```
core/        цикл игры, время и hit-stop, шина событий, FSM, математика, шум, настройки
input/       действия ввода, клавиатура/мышь/геймпад, буфер команд
physics/     статический мир коллизий (AABB, цилиндры, карта высот), контроллер капсулы
camera/      камера от третьего лица (коллизия, захват цели, тряска, кинематографический оверрайд)
render/      рендерер, пост-обработка, PBR-материалы, процедурные текстуры, модели оружия, профили графики
animation/   скелет-контракт, позы, клипы, аниматор, генерация клипов атак из фреймдаты
characters/  базовый персонаж, процедурный риг, плащ (verlet), игрок, враги, ИИ
combat/      типы урона, формула урона, данные атак, боевая система (хитбоксы, блок, парирование)
rpg/         характеристики, soft caps, прокачка, модификаторы (кольца, амулеты, баффы), вес снаряжения
items/       инвентарь и экипировка (оружие, броня, кольца, амулет), типы предметов, выдача добычи
magic/       типы заклинаний, снаряды, эффекты заклинаний (метеор, молния, разлом, баффы), призыв
vfx/         частицы, шлейфы, вспышки, ударные волны
world/       архитектура, палитра, алтари, сундуки, предметы, разрушаемые урны, огонь
world/environment/  время суток, погода, небо, облака, дождь
world/terrain/      раскладка мира, рельеф, вода, растительность
world/regions/      открытый мир (мосты, руины, замки, горы)
world/levels/       сборка уровня Ashen Gate
data/        все игровые данные (баланс, тексты, позы, привязки ввода)
save/        сохранения
ui/          HUD и меню
```

## Кадр

1. `InputManager.update` — физические события → действия (нажатие / удержание / отпускание).
2. `GameTime.advance` — масштаб времени и **hit-stop** (заморозка симуляции на 50–200 мс).
3. Персонажи: FSM состояния → желаемая скорость → `CharacterMotor` (под-шаги,
   ступеньки, склоны рельефа) → аниматор → поза на риг → сегмент клинка.
4. `CombatSystem.update` — свип-тест клинка (интерполяция между кадрами), ударные волны,
   телеграфы атак врагов.
5. Снаряды, разрушаемые объекты, окружение (время, погода, небо, IBL), камера, частицы, HUD, рендер.

## Бой

- `AttackData` — ассет атаки: позы (замах / удар / завершение), startup / active / recovery,
  стоимость выносливости, motion value, урон равновесию и по блоку, выпад, окно комбо,
  момент отмены перекатом, гиперброня, реакция, hit-stop, тряска, трекинг, ударная волна,
  телеграф. Анимационный клип **генерируется из этих чисел** (`attackClip`), поэтому
  анимация и окно попадания не могут разойтись.
- Конвейер попадания (`CombatSystem.resolve`): неуязвимость → парирование → блок
  (поглощение, выносливость, пробитие) → урон (`computeDamage`) → накопление статусов →
  равновесие → реакция → события для HUD/VFX.
- Формула урона (`combat/DamageCalculator.ts`): рейтинг атаки = база + масштабирование
  (грейды S–E × насыщение характеристики с soft caps) → × motion value × баффы →
  защита с убывающей эффективностью `raw² / (raw + def)` (не ниже 10%) →
  × (1 − поглощение/слабость) → × крит × контр-удар × дебаффы цели.

## RPG и экипировка

- `rpg/Modifiers.ts` — единый набор модификаторов (множители урона и магии, бонусы
  по типам урона, равновесие, регенерация, поглощение, лечение за убийство и т. д.).
  Кольца и амулет дают постоянные модификаторы, навыки оружия и заклинания —
  временные баффы; `Character.mods` складывает их и кэширует.
- `Player.applyProgress()` собирает итог: характеристики → броня
  (поглощение `1 − Π(1 − aᵢ)`, равновесие, сопротивления) → модификаторы → вес и тип
  переката → внешний вид (`HumanoidRig` пересобирается только при изменении облика).
- `items/Grants.ts` — одна точка выдачи добычи для сундуков, предметов мира и боссов.

## ИИ

Состояния: Idle, Patrol, Investigate, Return, Chase, Defend (кружение/блок), Attack,
Dodge, Stagger, Retreat, PhaseShift, CritVictim, Dead. Восприятие копит тревогу
(видимость в конусе, линия видимости по коллизиям и рельефу, шум от шагов/ударов);
реакции (уклон, блок) включаются только через ~0.6–0.7 с после обнаружения, поэтому
внезапная атака и удар в спину работают. Директор раздаёт токены атаки (элита стоит 2),
остальные держат дистанцию.

## Окружение

`EnvironmentSystem` каждый кадр: `TimeOfDay` (положение солнца/луны и палитра) +
`Weather` (облачность, дымка, дождь, плавные переходы) → цвета неба (`SkyDome`), облака
и ночное небо (`CloudLayer`), солнечный свет с тенями, следующими за игроком (снап
к текселям), полусферическое освещение, экспоненциальная дымка, карта окружения (PMREM)
пересчитывается при смещении солнца > ~1° или смене погоды.

## Замена ассетов

- **Персонажи**: риг реализует контракт суставов `animation/Skeleton.ts`. Скинованную
  glTF-модель можно подключить, сопоставив её кости этим именам, — клипы, аниматор
  и бой останутся без изменений.
- **Анимации**: клипы — данные (`data/poses.ts`, `HumanoidClips.ts`). Клипы из DCC
  можно проигрывать вместо процедурных, сохранив фреймдату атак как источник таймингов.
- **Оружие/окружение**: модели строятся функциями (`render/WeaponModels.ts`,
  `world/Architecture.ts`); их можно заменить загрузкой glTF без изменения логики.
- **Текстуры**: `render/TextureFactory.ts` — одна точка замены.

## Тесты

- `tests/*.test.ts` (vitest): формула урона, soft caps, прокачка, коллизии, контроллер
  движения (ступени, стены, падение, склоны рельефа), геометрия хитбоксов, FSM, буфер
  ввода, hit-stop, сэмплинг анимаций, целостность данных, валидация сохранений.
- `tools/smoke-test.mjs`: запускает собранную игру в headless Chromium и играет в неё
  через слой ввода — 59 проверок (движение, бой, ИИ, блок, парирование/рипост, заряд,
  заклинание, предметы, алтарь, прокачка, удар в падении, смерть и возврат эха, элита
  с двумя фазами, сохранение/загрузка, профили графики, выход в открытый мир, время
  суток, погода; добыча из каждого сундука и предмета мира, броня и кольца, вес
  и перекат, навыки оружия, метеор, заморозка, лечение, кровавая магия, призыв).
- `tests/rpgDepth.test.ts`, `tests/balance.test.ts`: модификаторы, сложение
  поглощения, классы веса, экипировка и сохранение инвентаря, целостность оружия,
  навыков, заклинаний и добычи; сравнение урона билдов силы, ловкости, мага и веры.
